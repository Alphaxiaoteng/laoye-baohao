# 老爷保号 · 项目亮点

> 面向初筛评委的一页说明：这个站做了什么、凭什么可信、后面怎么自己活下去。

## 一、视觉与交互底座

- **8787 深墨青沉浸空间**：`#243229` 深底 + 毛玻璃悬浮控件 + 珊瑚红行动色，全站统一 token，不换皮、不拼贴。
- **本地字体**：思源宋体可变字重自托管（10.4 MB），不依赖 Google Fonts，断网也能保持排版。
- **每页都有动效**：英歌五要素浮动贴图 + IntersectionObserver 下滑渐显；茶席 SVG 冲泡动画；攻略卡片入场位移；Agent 待机浮动与思考动作。全部尊重 `prefers-reduced-motion`。

## 二、英歌舞：两个界面讲完，不外跳

| 页面 | 内容 |
|---|---|
| `/museum/yingge` | 首屏五要素贴图（身体 / 双槌 / 锣鼓 / 角色 / 阵形），点哪块滚到哪段；下滑依次展开：演出片段、双槌对击互动、锣鼓合成节拍、角色职责表、七种阵形 3D 点位 |
| `/museum/yingge/story` | 历史 / 人物 / 队伍三条线索 + **木疙瘩 H5 数字馆离线内嵌**（331 个静态资源，71 MB，全部本地托管，0 跨域请求） |

- 原站 `5.mgd5.com` 外链**已彻底移除**，改站内镜像；外链只保留署名类（非遗名录、Wikimedia Commons）。
- 离线包删除了原页的 PV 统计脚本与外部 AI 导览注入，避免离线页被 `location.href` 劫持。

## 三、工夫茶：一页走完五步

- 砍掉 `/brew`、`/gesture` 两层跳转，恢复 TeaDemo 单页状态机；当前步骤对应的器物带柔光呼吸提示。
- **茶壶 / 茶荷 / 茶杯上都有点击热区**：点器物本身即推进「温杯 → 取茶 → 注水 → 出汤 → 敬茶」，不用找「下一步」。
- 摄像头手势保留为可选实验页，默认关闭，不请求权限。

## 四、潮汕攻略：真实小红书图文

- 抓取管线 `scripts/fetch-xhs-guide.mjs`：TikHub API → 关键词（潮州 / 汕头 / 揭阳 / 南澳岛 / 潮汕美食 / 潮汕菜做法）→ 清洗去广告去话题标签 → 本地封面自托管（统一压到 720px，49 张约 7.8 MB，懒加载）。
- 当前收录 **49 条**，按城市与类型筛选；每条保留**原作者、原帖链接、发布时间**，只做要点摘录，不做全文镜像。
- API Key 只从服务端环境变量读取，不进前端、不进仓库。

## 五、文献汇总：所有长文一页收口

- `/docs` 集中 27 条条目、5 章故事、4 道食谱，支持关键词过滤与锚点直达。
- 主演示页只负责看与点，考据与出处统一放这里，避免演示页变文档。

## 六、Agent：全站常驻、可拖拽、会动

- 右下角悬浮球：**按住可拖拽**，松手吸附最近左右边缘，位置记在 `localStorage`；点一下打开问答 / 听潮；抽屉与路由切换都有淡入，且尊重 `prefers-reduced-motion`。
- 形象为自绘英歌脸谱 + 双槌 SVG，四态：待机浮动、悬停倾斜、回答中摇摆、拖拽放大。
- 问答侧：站内检索（MiniSearch 中文单字 + 二字切分、标题加权、当前页加权、跨模块覆盖）→ 提示词约束 16 条 → 引用与导航白名单校验 → 密钥脱敏。
- **站外检索兜底**：配置 `WEB_SEARCH_URL` 后，站内只有 0–1 条结果时才联网；结果强制标注「站外来源，未核验」，编号 `[W#]` 与站内 `[S#]` 分开。未配置时完全关闭，不影响站内问答。

## 七、Agent 准确率怎么做实

- `npm run eval:agent`：**59 条**离线用例，覆盖英歌 / 工夫茶 / 美食 / 营老爷 / 攻略 / 跨模块 / 当前页上下文 / 实时信息拒答 / 提示注入。
- 当前结果：**检索命中 100%（59/59）**、确定性直答 8/8、检索 p95 **2.1 ms**。
- 检索层离线评测不调用模型、不产生费用；另有 `npm run eval:live` 做真实调用抽检：13 题全部有依据、0 编造、实时信息正确拒答、提示注入被拒绝，单题 2.7–5.0 秒。详见 `docs/AGENT-EVAL.md`。
- 明确的不猜策略：没有步骤号就问「哪一步」；实时信息（今天几点 / 门票多少）直接说没有实时数据；资料没有的史实不补写。

## 八、内容可信度

- 每条内容带 `sourceIds` 与核验状态（已核验 / 待本地核验）；来源表 **99 条**逐条登记机构、访问日期、适用地区、许可。
- 食谱来自团体标准与政府门户：潮州牛肉丸（T/CZSPTXH 108-2019）、牛肉粿条汤（T/CZSPTXH 001-2018）、蚝烙、潮州卤鹅，用量与工序能对回原文。
- 未能核验的部分明确标注，不做「看起来很像」的补写。

## 九、自维护：后期几乎不用人管

目标形态：**每天只需续费 Key，内容和知识库由后端 Agent 自己更新与筛选。**

| 环节 | 做法 | 现状 |
|---|---|---|
| 内容体检 | `scripts/self-maintain.ts` 每日跑校验、来源新鲜度、攻略时效 | 已实现（可 cron） |
| 资讯更新 | RSS / TikHub 抓取 → 去重 → LLM 摘要 → 写入 `draft` | 抓取与清洗已实现，LLM 摘要需模型 Key |
| 审核门禁 | 白名单来源自动发布，其余进人工队列；失败不覆盖线上 | 规则已写进脚本 |
| 用户习惯 | 匿名记录打开条目与提问主题 → 提升相关条目检索权重 | 预留字段 `visited` 已接入 |
| 失效回滚 | 校验不通过即保留上一版内容并告警 | 校验失败非零退出 |

## 十、工程与安全

- `typecheck` / `test`（17 文件 154 用例）/ `build` / `validate` / `eval:agent` 全绿。
- 密钥只走环境变量；日志与错误事件经 `redactSecrets` 脱敏；前端 bundle 不含任何 Key。
- Docker 运行时 `COPY public`，展内静态资源不会退化成 200 HTML；缺失资源返回真 404。
- 未 commit、未 push，等你确认。
